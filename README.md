# 🤖 通用 RAG 智能问答系统 (v3.1.0)

> **项目简介**：基于本地大模型与 RAG（检索增强生成）技术的智能问答平台。支持多格式文档上传、混合检索模式及流式输出，专为垂直领域知识库构建设计。

## 📸 系统界面预览

下图展示了系统基于《治安管理处罚法》文档进行 RAG 检索增强的实际运行效果：

![系统运行截图](通用RAG智能问答系统（智能问答）.png)

> **如图所示**：
> - **左侧控制台**：支持调节温度参数、检索数量，支持文档上传与处理。
> - **中间对话区**：针对“治安管理处罚法规定”的提问，系统精准检索并总结了处罚种类、正当防卫界定、新增违法行为等关键点。
> - **右侧功能区**：提供知识库管理、灵活配置及历史记录等辅助功能。

## ✨ 核心功能
- **📚 多格式文档支持**：支持 PDF、Word 等多种格式文档的一键上传与解析。
- **🔍 混合检索模式**：采用 Hybrid 检索策略，结合关键词与向量检索，提高召回准确率。
- **⚡ 流式输出**：支持类似 ChatGPT 的打字机效果，提升用户交互体验。
- **🛠️ 灵活配置**：可实时调整模型参数（如 Temperature），适应不同问答场景。

## 🚀 快速启动 (Windows)

本项目已封装为 Windows 批处理脚本，无需复杂的环境配置即可运行：

1. 克隆仓库到本地。
2. 双击运行 `Demo启动菜单.bat`。
3. 根据菜单提示选择功能（如启动 RAG 系统、启动仿真等）。

## 📂 脚本说明

| 文件名 | 说明 |
| :--- | :--- |
| `Demo启动菜单.bat` | 主入口，集成所有功能 |
| `一键启动RAG系统.bat` | 单独启动问答系统 |
| `启动PyBullet仿真.bat` | 启动物理仿真环境 |
