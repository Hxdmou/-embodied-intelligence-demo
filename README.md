# Embodied Intelligence Demo (具身智能体演示系统)

> **项目简介**：这是一个基于本地大模型驱动的具身智能体系统。集成了 RAG（检索增强生成）知识库与 PyBullet 物理仿真环境，实现了从“知识问答”到“仿真控制”的闭环演示。

##  核心亮点
- **（本地大模型驱动）**：无需联网，基于本地算力运行，数据隐私安全。
- **（RAG 知识库增强）**：挂载外部知识库，解决大模型幻觉，提供精准的专业领域问答。
- **（PyBullet 物理仿真）**：在虚拟环境中模拟机器人运动与控制，验证智能体决策能力。
- **（一键式部署）**：全 Windows 环境适配，提供傻瓜式 `.bat` 启动脚本，降低演示门槛。

## 🛠️ 功能模块说明

本仓库包含多个独立启动脚本，对应系统的不同功能模块：

| 脚本名称 | 功能描述 |
| :--- | :--- |
| `Demo启动菜单.bat` | **主入口**：交互式菜单，可自由选择启动各项功能。 |
| `一键启动RAG系统.bat` | 启动 RAG 知识库问答服务，支持本地文档检索。 |
| `启动PyBullet仿真.bat` | 启动 PyBullet 物理引擎，加载仿真场景。 |
| `启动训练好的智能体.bat` | 加载预训练模型权重，展示智能体自主行为。 |
| `合并模型到本机.bat` | 工具脚本：用于将微调/量化后的模型合并部署。 |
| `关闭所有系统.bat` | 安全退出：一键清理后台进程，释放显存/内存。 |
